# 🖋️ Verso

**Verso** — это современное веб-приложение для заучивания стихотворений и текстов наизусть. Создано с акцентом на чистый книжный дизайн (в духе нативных iOS-приложений), максимальную мобильную эргономику и надежность сохранения данных.

🔗 **[Открыть Demo на Vercel](https://verso-school.vercel.app)**

---

## 🏗️ Архитектура (Local-first & Cloud Catalog)

Verso спроектирован по принципу **Local-first** с гибридными облачными сервисами:

```
Verso
├── 📱 Local-first (Устройство пользователя)
│   ├── localStorage  → Личная библиотека (мгновенный доступ, 100% офлайн)
│   └── Backup        → Экспорт и импорт библиотеки в JSON-файлы
│
└── ☁️ Supabase Cloud (PostgreSQL + RLS)
    ├── 📖 catalog_poems  → Публичный каталог классических стихотворений
    │                       (живой поиск, фильтрация по авторам, 1-click импорт)
    ├── 🔗 shared_poems   → Короткие ссылки для шеринга стихов (?p=abcdef12)
    └── 🛡️ RPC Security   → Точечный доступ по ID, блокировка утечек и спама
        Fallback:
        └── lz-string     → Автономный шеринг (?share=...) без подключения к сети
```

1. **Приватность и локальность**: Все ваши личные стихотворения хранятся исключительно в памяти вашего устройства (`localStorage`). Никто посторонний не имеет доступа к вашей библиотеке.
2. **Облачный каталог классики**: Доступ к обширной базе стихотворений с удобным живым поиском и добавлением в личную библиотеку в один клик.
3. **Безопасный шеринг через Supabase**:
   - При создании ссылки генерируется 8-значный криптографический ID (`?p=...`).
   - На уровне базы данных включен **Row Level Security (RLS)**: прямой запрос на чтение всей таблицы чужих стихов (`SELECT *`) запрещен. Доступ возможен только точечно по конкретному ID через функцию `get_shared_poem`.
4. **Резервное копирование**: В разделе «Профиль» доступен экспорт библиотеки в `.json` и безопасный импорт с предотвращением случайной перезаписи.
5. **Офлайн-fallback**: Если сервер недоступен, приложение сжимает стихотворение в ссылку через `lz-string` (`?share=...`), сохраняя полную автономность.

## 🚀 Основные возможности

### 📖 Облачный каталог классики
- Встроенная библиотека произведений великих классиков (Пушкин, Лермонтов, Есенин и др.).
- Мгновенный живой поиск по автору, названию, строкам текста и тегам.
- Фильтры по авторам с горизонтальным скроллом и изоляцией жестов (без раскачивания страницы на iOS Safari).
- Умная синхронизация: карточка каталога на лету отслеживает, есть ли стихотворение в вашей библиотеке, отображая статус «В библиотеке», и возвращается к кнопке «Добавить», если стих удалён.
- 1-клик запуск тренировки без создания дубликатов.

### 📚 Библиотека и резервные копии
- Сетка карточек с быстрым переходом к заучиванию.
- Редактирование текста и названия.
- Резервное копирование: сохранение библиотеки в JSON-файл и восстановление в один клик.

### 📷 Умное добавление через фото (OCR)
- Распознавание страниц книг прямо с камеры смартфона с помощью нейросетевого движка Tesseract.js (модель `rus`).
- Автоматический препроцессинг (повышение контрастности и перевод в ч/б) для качественного считывания при неровном освещении.
- Гарантированная очистка ресурсов и фонового воркера.

### 🧠 Алгоритмы запоминания
1. **Ластик:** Плавно стирает случайные слова из текста, заменяя их на нижние подчеркивания `___`. Чем выше сложность на ползунке, тем больше слов скрыто.
2. **Первые буквы:** Заменяет слова на их первые буквы, бережно сохраняя структуру строф и знаки препинания. Идеально для перехода от подсказок к чтению наизусть.
3. **Интерактивные подсказки:** Нажатие на скрытое слово открывает его на заданное количество секунд (с плавно уменьшающейся полосой таймера) или в режиме «по тапу».

### 🎛️ Гибкая настройка тренировки
- Автоматическая разбивка на строфы/части по пустым строкам («Часть 1», «Часть 2»...) или тренировка всего текста целиком («Выбрать все»).
- Выбранный уровень сложности (процент скрытия) сохраняется между переключениями стихотворений.
- Настраиваемый шаг ползунка (`1%`, `5%`, `10%`, `20%` или произвольный).

### 🎨 Персонализация и темы
- Поддержка **Светлой**, **Тёмной** и **Системной** темы оформления.
- Полная адаптация под iOS Safari с учётом полосы домашнего экрана (`safe-area-inset-bottom`).

## 🛠️ Технологический стек

- **Frontend:** React 19 + Vite
- **Стили:** Vanilla CSS + Tailwind CSS v4
- **OCR:** Tesseract.js (`rus` / `tessdata_best` + HTML5 Canvas)
- **База данных и RPC:** Supabase PostgreSQL с Row Level Security (RLS)
- **Сжатие ссылок:** `lz-string`
- **Иконки:** `lucide-react`
- **Тестирование:** Vitest

## 📦 Локальный запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/kingVitya/verso.git
   cd verso
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
4. Запустите тесты:
   ```bash
   npm run test
   ```
